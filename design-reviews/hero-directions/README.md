# Ashira Tantra — revised hero studies

Three isolated browser-rendered HTML studies using the supplied practice video and the original Meno Banner / Archivo Narrow font faces. These PNG files show the desktop (1440×1000) and mobile (390×940) layouts. The main site has not been changed by this review commit.

- Editorial: icy blue, cobalt and fuchsia; wide cinematic film.
- Kinetic: cobalt stage with large asymmetric film and monumental type.
- Cinematic: full-screen practice footage and luminous edge light.

Only review images are published on this branch. No production deployment.
